📤 Wonderzyme Data Import

Restore your data to new Supabase project

📋 How to Use:

  1. Deploy Edge Function to your NEW Supabase project
  2. Copy Project URL from Settings → API
  3. Copy anon public key from Settings → API
  4. Select your backup JSON file
  5. Click "Import Data" to restore everything
